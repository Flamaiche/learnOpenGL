# 🔺 learnOpenGL — Labo de rendu 3D en Java

Apprentissage d'**OpenGL (LWJGL)** en Java : du premier triangle aux shaders,
textures et caméras — petites démos organisées par étape.

Base de mon projet [SpaceShooter](https://github.com/Flamaiche/SpaceShooter) :
j'y apprends chaque brique (rendu, matrices, éclairage) avant de l'intégrer
au jeu.

## Pourquoi ce repo ?

Montrer le *chemin* : chaque dossier est une étape de mon apprentissage du
rendu 3D bas niveau.
